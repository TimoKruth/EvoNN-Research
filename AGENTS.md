# Project instructions

For every newly planned engine comparison, run **Prism, Topograph, Stratograph
and Primordia** on every declared benchmark/budget/seed combination. Include
Contenders as additional baselines. Focused hypotheses may narrow the statistical
tests, but must not narrow the engine roster or omit engines from the report.

Do not silently exclude an engine because it is weak, unfinished or fails. Record
the failure and mark the comparison incomplete until the execution problem is
resolved. Preserve frozen historical protocols and results; this rule governs
new comparisons and does not authorize changing completed evidence.

Use README.md for operation and CONSOLIDATED_PLAN.md for current next steps.
