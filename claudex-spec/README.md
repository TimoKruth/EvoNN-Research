# Product interop reference

This Lab repository retains only [the Product consumer contract](19-research-interop.md).
It defines Product-owned acceptance and the boundary for Lab artifacts.
The complete Product architecture, UX, roadmap, ADRs, schemas and examples
belong to the separate Product workstream; they are not Lab implementation scope.

The original Product reference corpus is available at the exact historical
[Git tree](https://github.com/TimoKruth/EvoNN-Research/tree/836cfffc204babab70f8c222b45668df03e04564/claudex-spec).
References in the historical program charter to Product chapters 00, 09, 15,
18 and Product traceability resolve in that snapshot. The interop chapter's
bytes and authority pin remain unchanged.

In a full clone, retrieve any original with:

```sh
git show 836cfffc204babab70f8c222b45668df03e04564:claudex-spec/<original-path>
```
