# Primordia configurations

`standard.yaml` selects the tested `full_steady` policy combination. `portfolio.yaml`
and `portfolio_stable.yaml` select experimental recurring family exploration with
constant and cosine learning-rate schedules respectively. These are runnable
64-fit native CPU configurations; increase budgets explicitly for a planned study.
They do not claim a new all-engine qualification.

`research_v3/` contains 13 explicit, opt-in Primordia presets. See the
[research controls and all-engine spec generator](../README.md#opt-in-v3-research-arms).
